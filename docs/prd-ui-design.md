# PRD واجهات «المحوّل» — للتصميم في Claude Design

> هذا المستند مكتوب ليُلصق مباشرة في Claude Design.
> المنتج مبني ويعمل (Next.js — RTL عربي)؛ المطلوب: تصميم واجهات أجمل وأكثر تفاعلية لنفس الرحلة، شاشة بشاشة.

---

## 1. المنتج في سطر

«المحوّل» منصة عربية تحوّل وصف الموظف لمهمته المتكررة — بكلامه العادي — إلى أتمتة حقيقية تعمل عنه، مع موافقته الصريحة على أي إجراء حساس.

## 2. المستخدم المستهدف

**الموظف الواعي رقمياً**: يعرف مهامه المتكررة ويكره تضييع وقته فيها، يستخدم Gmail وGoogle Sheets وTelegram يومياً، **لا يكتب كوداً ولا يريد رؤية أدوات تقنية**. يريد أن: يصف مهمته → يشاهدها تتحول لرسم واضح → يربط حساباته بضغطة → يجرب بأمان → يشغّل وهو مطمئن أن لا شيء حساس يحدث بدون إذنه.

## 3. العبارة الرئيسية (Hero) — مصقولة

- **العنوان الرئيسي:** «أتمت شغلك اليومي المتكرر»
- **السطر الثاني (تدرج لوني على كلمة تشتغل):** «صِفه بكلامك… وخلّه يشتغل عنك»
- **الوصف:** «المحوّل يفهم مهمتك، يقيّمها بصراحة، يبنيها، يجرّبها أمامك — ولا يرسل أو يحذف شيئًا أبدًا إلا بموافقتك.»
- **زر CTA رئيسي:** «ابدأ الأتمتة الأولى ←»
- **زر ثانوي:** «شاهد كيف تعمل»
- بدائل للعنوان (اختر الأجمل بصرياً): «وقتك أثمن من المهام المتكررة» / «من وصف المهمة… إلى أتمتة تعمل».

## 4. مبادئ التصميم

1. **عربي RTL أولاً** — كل الشاشات من اليمين لليسار، الأرقام والأكواد LTR داخل حاوياتها.
2. **بساطة أمام الموظف، قوة خلف الكواليس** — لا تظهر أبداً كلمات: n8n، workflow JSON، API، webhook. المصطلحات المسموحة: «مسار»، «أتمتة»، «محرك التنفيذ»، «ربط الحساب».
3. **الثقة عنصر تصميم** — الموافقات والإجراءات الحساسة لها لغة بصرية مميزة (كهرماني/أحمر + درع 🛡️) في كل الشاشات.
4. **الحالة دائماً ظاهرة وحية** — كل مسار له شارة حالة ملونة تتحدث لحظياً (استطلاع كل 3 ثوانٍ).
5. **تفاعلية ممتعة بلا ضجيج** — انتقالات ناعمة 150-250ms، hover يرفع البطاقات 1px، نجاح الاختبار يستحق لحظة احتفال (confetti خفيف مرة واحدة)، بث نص المحادثة حرفاً بحرف.

## 5. نظام التصميم (الحالي — حافظ عليه وطوّره)

- **الخلفية:** `#0a0e1a` داكنة مع توهجين قطريين خافتين (بنفسجي `#a78bfa` أعلى اليسار، سماوي `#22d3ee` أسفل اليمين).
- **البطاقات:** زجاجية خفيفة: تدرج أبيض 4%→1%، حد `#23304a`، زوايا 16px، blur خفيف.
- **الألوان الدلالية:** أساسي (أزرار CTA) تدرج `#22d3ee → #6366f1` — نجاح `#34d399` — تحذير/موافقات `#fbbf24` — خطر/رفض `#f87171` — نص ثانوي `#8b9bb8`.
- **الخط:** IBM Plex Sans Arabic (أوزان 300-700).
- **الشارات (chips):** كبسولات صغيرة بحد ولون دلالي — تُستخدم للحالات ودرجة الجدوى وأنواع الحلول.
- **الأيقونات:** شعارات الخدمات الحقيقية الملونة (Gmail, Google Sheets, Drive, OpenAI, Telegram, Slack) داخل مربع داكن 36-40px بزوايا 10px.

## 6. خريطة الشاشات

```
الهبوط → تسجيل الدخول → اللوحة الرئيسية
                              ├─ محادثة «أتمتة جديدة»
                              │     └─ بطاقة الملخص + الربط → صفحة المسار
                              ├─ صفحة المسار (تقييم | رسم | اختبار وتشغيل)
                              ├─ الحسابات المتصلة (إعدادات)
                              └─ الإعدادات (حسابي + منطقة الخطر)
```

## 7. الشاشات — مواصفة تفصيلية

### 7.1 شاشة الهبوط (Landing)

- Hero بالعبارات من قسم 3، بخلفية متوهجة وحركة دخول متدرجة (العنوان ثم الوصف ثم الزر).
- شريط «كيف تعمل» من 4 خطوات بأيقونات كبيرة وخط متصل متحرك: **احكِ** 🎙️ → **قيّم** ⚖️ → **اربط وجرّب** 🧩 → **شغّل بموافقتك** 🛡️.
- شريط شعارات الخدمات المدعومة (الأيقونات الست) مع نص: «يتصل بأدواتك التي تستخدمها كل يوم».
- بطاقة اقتباس تجريبية: مثال محادثة قصير (سؤالان) يظهر بالتتابع كأنه حي.
- Footer بسيط.

### 7.2 تسجيل الدخول

- بطاقة مركزية واحدة: بريد + كلمة مرور + زر «دخول»، وتبديل «أنشئ حساباً».
- رسالة طمأنة تحتها: «محادثاتك ومساراتك واتصالاتك ملكك وحدك».
- (مستقبلاً: أزرار Google/Microsoft بنفس نمط بطاقات الربط — اتركها معطلة بشارة «قريباً»).

### 7.3 اللوحة الرئيسية (Dashboard)

- ترحيب شخصي أعلى: «أهلاً {الاسم} 👋 — وش المهمة اللي بنوفر وقتها اليوم؟» + زر كبير «+ أتمتة جديدة».
- **شريط موافقات معلقة** (إن وُجدت): بطاقة كهرمانية لافتة أعلى الصفحة بعداد نابض، كل صف يفتح مساره مباشرة.
- شبكة بطاقات المسارات (عمودان): اسم المسار، شارة حالة، درجة الجدوى، أيقونات الخدمات المستخدمة مصغرة، آخر تشغيل. hover يضيء الحد سماوياً.
- **حالة فارغة** مصممة بعناية: رسم لطيف + «لا مسارات بعد — أول أتمتة تاخذ 5 دقائق» + زر البدء.
- شارات الحالة (بالعربية): مسودة / تحتاج معلومات / تحتاج ربط حسابات / جاهزة للاختبار / قيد الاختبار / تحتاج إصلاحاً / جاهزة / **مفعّلة** (نجاح متوهج) / متوقفة / غير مناسبة.

### 7.4 شاشة المحادثة (المقابلة الذكية)

- تخطيط دردشة مريح بعرض محدود (720px): فقاعات المستخدم يمين بلون سماوي شفاف، وفقاعات «المحوّل» يسار كبطاقات.
- **النص يُبث حرفاً بحرف** مع مؤشر كتابة (3 نقاط نابضة).
- شريط علوي رفيع: «مقابلة المهمة» + مؤشر تقدم خفيف من 4 مراحل (الوصف → الخطوات → التفاصيل → التأكيد) يتلون كلما تقدمت المحادثة.
- عند التأكيد: تنزلق **بطاقة الأتمتة** (7.5) داخل المحادثة نفسها بحركة ظهور.
- حقل الإدخال ثابت أسفل، placeholder: «اكتب هنا…»، زر إرسال بتدرج الأساسي.

### 7.5 بطاقة الأتمتة الملخصة (المكوّن النجم — داخل المحادثة وفوق الرسم)

- سطر رسالة قصير: «جاري تجهيز الأتمتة. يرجى ربط الحسابات التالية لتمكين النظام من التنفيذ:».
- سطر تعريف: اسم المسار + شارة «الجدوى 97/100» خضراء + شارة النمط (مثل `Hybrid (n8n + AI + Human-in-the-loop)` — LTR).
- **شبكة بطاقات الربط**: (انظر مكوّن 8.1) — قلب هذه البطاقة.
- جدول خطوات مضغوط: # / الخطوة / شارة النوع الملونة (ثابت=رمادي، ذكاء اصطناعي=بنفسجي، وكيلي=فوشيا، موافقة بشرية=كهرماني) / الأداة / عمود 🛡️.
- سطر حالة المحرك أسفل + زر «🚀 إنشاء الحل في محرك التنفيذ» يظهر فقط عند اكتمال الربط (بحركة ظهور مُرضية).

### 7.6 شاشة التقييم

- **عداد دائري كبير متحرك** (يتعبأ من 0 للدرجة خلال ثانية) — أخضر فوق 55، أحمر تحته.
- حكم واضح بجانبه: «✓ مناسبة للأتمتة» أو «✗ غير مناسبة حالياً» + شرح بجملة واحدة + شارات أنواع الحل.
- عمودان: **البوابات الإلزامية** (قائمة ✓/✗ مع سبب لكل بند) و**عوامل التقييم** (أشرطة تقدم متدرجة تتحرك عند الدخول، لكل عامل سبب صغير تحته).
- بطاقة كهرمانية «معلومات ناقصة تحسّن النتيجة» عند وجودها، مع زر «أكمل المقابلة».

### 7.7 شاشة الرسم البصري (المسار)

- تبويبات الصفحة: ⚖️ التقييم | 🧩 الرسم والربط | ▶️ الاختبار والتشغيل.
- بطاقة الأتمتة (نسخة الربط فقط) أعلى الرسم.
- **الكانفس**: عقد تتدفق **من اليمين إلى اليسار** على خلفية نقاط خافتة، الخطوط متحركة (animated dashes).
- **العقدة**: بطاقة 224px فيها: أيقونة الخدمة في مربع + اسم الخطوة + العملية بخط صغير + شارات: «متصل» أخضر / «يحتاج اتصالاً» كهرماني / «إرسال — بموافقتك» أحمر. عقدة الموافقة لها شكل مميز بحد كهرماني ودرع.
- عقدتا البداية «▶️ بداية المهمة» والنتيجة «🏁 النتيجة» بحد سماوي.
- الضغط على عقدة يفتح **درجاً جانبياً** (وليس بطاقة تحت): التفاصيل، المعاملات، وزر الربط/الفصل الخاص بخدمتها — ومنه إدخال مفتاح OpenAI بحقل سري مع ملاحظة «يُحفظ مشفراً في خزنة المحرك ولن يظهر مجدداً».
- زر «🚀 إنشاء/إعادة البناء» أعلى يسار الكانفس.

### 7.8 شاشة الاختبار والتشغيل

- **قسم الاختبار**: زر «شغّل الاختبار» + جملة الأمان الدائمة: «الإجراءات الحساسة لا تُنفَّذ في الاختبار — تظهر كمعاينة فقط».
  - بطاقة نتيجة لكل تشغيل: شارة (⏳ قيد التنفيذ نابضة / ✓ نجح / ✗ فشل) + ثلاثة أعمدة كود LTR: المدخل / المتوقع / الفعلي.
  - عند الفشل: سطر أحمر واضح «فشل عند العقدة «اسم العقدة»: السبب» + زر «افتح العقدة» يقفز للرسم.
  - **عند أول نجاح: لحظة احتفال** — confetti خفيف + تحول الحالة لـ«جاهزة».
- **قسم التفعيل والتشغيل**: مفتاح تفعيل كبير (Active toggle) بدل زر عادي + زر «▶️ تشغيل الآن».
- **بطاقة الموافقة** (أهم عنصر ثقة): حد كهرماني متوهج نابض بلطف، عنوان «🛡️ موافقتك مطلوبة: إرسال إيميل تأكيد»، ملخص الإجراء، صندوق يعرض **الشيء الفعلي الذي سيُرسل** (نص الإيميل)، وزران كبيران: «✓ أوافق على التنفيذ» (أساسي) و«✗ أرفض» (أحمر شفاف). بعد القرار تتجمد البطاقة بحالة نهائية.
- سجل «آخر التشغيلات»: صفوف زمنية بشارات (نجح/يعمل/بانتظار موافقتك/رفضته/خطأ).

### 7.9 شاشة الحسابات المتصلة ⭐ (بنمط الصورة المرجعية المرفقة)

قائمة صفوف داخل بطاقة واحدة — كل صف:

```
[أيقونة الخدمة الملونة]  اسم الخدمة        [زر الحالة]
```

- **متصل** ← زر «فصل الاتصال» أحمر ممتلئ (مثل Disconnect في المرجع) + شارة ✓ خضراء صغيرة بجانب الاسم.
- **غير متصل** ← زر «+ ربط» بحد رمادي يتحول لتدرج الأساسي عند hover.
- **قيد الربط** ← spinner داخل الزر.
- الخدمات: Gmail، Google Sheets، Google Drive، OpenAI (بحقل مفتاح)، Telegram، Slack.
- تحت القائمة قسم **«تحتاج خدمة ثانية؟»**: صف بأيقونة ➕ ونص «اطلب ربط أي موقع أو أداة تستخdمها — نضيفها لك» + حقل إدخال وزر «أرسل الطلب». (هذا يحقق «الربط مع أي موقع يبيه» كطلب تكامل — الكتالوج الفعلي الحالي 6 خدمات).
- كل ربط/فصل يسجَّل بسطر صغير: «آخر استخدام: قبل ٤ دقائق».

### 7.10 الإعدادات ومنطقة الخطر

- بطاقة «حسابي»: البريد، تغيير كلمة المرور، تسجيل الخروج.
- **منطقة الخطر** (بنمط المرجع): بطاقة بحد أحمر، «حذف الحساب — سيؤدي لحذف كل مساراتك واتصالاتك نهائياً»، زر «حذف» أحمر يفتح تأكيداً مزدوجاً (اكتب «حذف» للتأكيد).

## 8. المكوّنات المشتركة

### 8.1 بطاقة التكامل (Integration Card)
مربع عمودي: أيقونة الخدمة → الاسم → زر الحالة. الحالات الأربع: غير متصل (زر «+ Connect Gmail» بالتدرج) / قيد الربط (spinner) / متصل (شارة «✓ متصل» خضراء والبطاقة تتوهج أخضر خفيف لثانية عند النجاح) / خطأ (حد أحمر + رسالة قصيرة).

### 8.2 شارة الحالة، 8.3 بطاقة الموافقة، 8.4 فقاعات المحادثة، 8.5 العقدة — كما وُصفت أعلاه؛ صمّمها كمكوّنات قابلة لإعادة الاستخدام بنفس اللغة البصرية.

## 9. نغمة الكتابة (Microcopy)

عربية بيضاء ودودة ومباشرة، تخاطب بصيغة «أنت»، بلا مصطلحات تقنية. أمثلة جاهزة:
- نجاح الربط: «تم ربط Gmail ✓»
- نجاح الاختبار: «الاختبار نجح — مسارك جاهز للتفعيل 🎉»
- فشل: «توقفنا عند خطوة «تسجيل الصف» — السبب: … عدّلها ونعيد المحاولة»
- انتظار موافقة: «المسار واقف ينتظر قرارك — ما نرسل شيئًا بدونك»
- تشغيل: «انطلق المسار… تابعه هنا لحظة بلحظة»

## 10. ملاحظات ربط بالتنفيذ الحالي (للمطور بعد التصميم)

- المسارات: `/` `/login` `/dashboard` `/chat` `/flow/[id]?tab=evaluation|canvas|run` + شاشة الاتصالات الجديدة `/settings/connections`.
- البيانات جاهزة من: `GET /api/flows/[id]/summary` (بطاقة الأتمتة كاملة)، `GET /api/connections`، `POST /api/connections`، `POST /api/flows/[id]/{build|test|run|activate}`، `POST /api/approvals/[id]`.
- الرسم مبني على React Flow — صمّم العقدة كبطاقة HTML حرة الشكل.
- الحالات تُستطلع كل 3.5 ثانية — صمّم كل القوائم لتقبل التحديث الحي بدون قفزات.
